# Changelog

## 0.1.0

Initial Windows release.

- Save links through a configurable Capture shortcut, with a prompted editor or Quick-save to Inbox. Find links using the floating Search shortcut.
- Organize the local library with categories, groups, pins, drag-and-drop ordering and link metadata.
- Confirm a new save with Link Flight. Duplicate feedback shows the existing link and collection. Glass panels offer appearance controls and reduced-motion and solid-material alternatives.
- Back up and restore with optional Google Drive integration. Release builds include the Desktop OAuth configuration. Backup history shows dates and available metadata. A successful restore opens the Library and retains a local recovery copy.
- Install per user on Windows 11 x64. The tray stays available while the Library is hidden. Sign-in startup can be disabled in Settings.
- Check for newer eligible releases from the Library and install them manually from GitHub.

The installer is unsigned. See [known limitations](docs/USAGE.md#known-limitations).
