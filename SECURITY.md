# Security policy

Report vulnerabilities in the latest Linkme release through [GitHub's private vulnerability reporting](https://github.com/medsallemi/linkme/security/advisories/new) when available. If that option is unavailable, contact the maintainer at [machekelsallemi@gmail.com](mailto:machekelsallemi@gmail.com) to arrange a private channel.

Include the affected Linkme version, Windows and WebView2 versions, and a minimal reproduction with synthetic data. For installer issues, include the installer SHA-256 and whether Windows reports a publisher signature. Keep authentication tokens, Google account data, private URLs and database copies out of reports and public issues.

The [privacy documentation](docs/PRIVACY.md) explains data storage and permissions.
